# Gladiator BJJ — интеграция магазина экипировки

Дата: 25 ноября 2026. Основа: актуальный архив Gladiator BJJ. Донор: актуальный архив Kickboxing-Khakassia. Стек и версии зависимостей не изменены: Node.js 24, Express ESM, Prisma 6.19.3, SQLite, SCSS, JavaScript.

## Перенесённые механизмы

| Механизм донора | Реализация в Gladiator BJJ |
|---|---|
| Витрина, карточка и детальная страница | /shop, /shop/:slug; только опубликованные товары |
| Быстрый просмотр | Правая панель на больших экранах, диалог на мобильных |
| Категории, поиск по названию/категории/описанию, диапазон цен, сортировка | Серверная фильтрация; пустое состояние, сброс фильтров |
| Варианты | Код, размер/цвет, цена в копейках, доступность |
| Корзина | /cart; localStorage bjj-shop-cart-v1, счётчик в общем хедере, количество, удаление позиции, синхронизация вкладок |
| Заявка | Имя, телефон, отдельное согласие, проверка наличия и цены на сервере, номер заявки, повтор без дублирования при неизменных данных |
| Документы | /shop-policy, /shop-consent; реквизиты оператора, включение/отключение приёма, контроль актуальности версии согласия |
| Админка | /admin/shop; товары, заявки, реквизиты и документы; защита от ухода с несохранённой формы |
| Товары | Создание, обновление, публикация/скрытие, удаление с подтверждением и проверкой версии |
| Категории | Присваиваются и изменяются в редакторе конкретного товара, как у донора; отдельной вкладки нет |
| Фото | JPEG/PNG/WebP до 6 МБ, Sharp, поворот и преобразование в WebP до 1400 × 1400, замена/отвязка изображения |
| Заявки в админке | Пагинация, контакт и снимок состава и цены, статусы new/review/agreed/closed, удаление с подтверждением |
| Права доступа | Только OWNER, магазин общий для клуба и не зависит от выбранного зала |
| Журнал | Действия с товарами, фото, документами и заявками фиксируются в AuditLog, доступны владельцу |
| Навигация и оформление | Общий хедер, мобильное меню, поиск по разделам, футер; Black Belt, Roboto Condensed, общие микроанимации, жёлтая админка |

Публичные маршруты API: GET /api/shop/products, POST /api/shop/requests, GET /media/shop/:name.

Административные маршруты API (префикс /api/admin/shop):
- GET /products; POST /products; PATCH и DELETE /products/:id.
- POST /images; GET /images/:name.
- GET и PUT /settings.
- GET /requests?page=0; PATCH и DELETE /requests/:id.

Документы и карточки получают собственные заголовки и описания. Политика индексирования всего Gladiator BJJ оставлена прежней (noindex); SEO-инфраструктура и PWA кикбоксинга не заменяют отложенные этапы сайта Gladiator BJJ.

Как в доноре, категория — значение в товаре, а не самостоятельная запись. Пустой категории нет. Категория исчезает из витрины, когда в ней больше нет опубликованных товаров. Изменение категории выполняется только в редакторе товара. Фотографии хранятся за пределами публичной директории, в var/shop-media/. После снятия публикации либо удаления товара фото перестаёт отдаваться публично, если на него не ссылается другой опубликованный товар. Замена/отвязка фото не уничтожает файл на диске (поведение донора). При резервном копировании сервера сохранять также var/shop-media/.

## Миграция и запуск (Windows CMD)

Распаковать патч в корень существующего проекта с заменой файлов. Существующий .env и SQLite оставить.

```cmd
npm ci
npm run db:generate
npm run db:backup
npm run db:deploy
npm run build:public
npm run build:admin
npm test
npm start
```

Команда db:backup нужна, если локальная база уже существует. Для нового проекта без базы сначала применить миграции. Новая миграция 202611240001_shop добавляет только три таблицы и их индексы; начальная миграция не менялась.

Открыть http://localhost:3000/shop и http://localhost:3000/admin/shop (или указанный в APP_ORIGIN адрес).

В «Магазин → Реквизиты и документы» владелец должен заполнить реальные данные оператора, тексты политики и согласия и включить приём заявок. До этого витрина доступна, но оформление заявок отключено. Товары и реальные реквизиты чужой федерации не переносятся; новая витрина заполняется владельцем клуба.
